\abstract{%
  % english
  This thesis focuses on the detection of toxic text in a web browser environment and on the development of a browser extension named \textit{Toxic Text Detector}. The aim of the work is to provide users with a practical tool for identifying potentially harmful online content while preserving user control and privacy. The solution was designed and implemented as a Chrome Manifest V3 extension. It uses a React-based user interface, a content script for working with web page text, a service worker for communication between components, persistent settings and two inference modes. The local mode performs classification directly in the browser, while the remote mode uses an external API through a backend service. The implemented extension can analyze selected text or text elements on a page, mark potentially toxic content, blur it visually and display the detected category together with a confidence score. The solution was evaluated through user interface testing and model experiments focused on local and remote inference. The results show that a hybrid browser-based approach can provide a practical compromise between detection quality, latency, usability and privacy protection. At the same time, the work confirms that toxicity detection remains challenging, especially for minority categories and more context-dependent forms of harmful language.
}{%
  % slovak
  Táto práca sa zameriava na detekciu toxického textu v prostredí webového prehliadača a na vývoj rozšírenia s názvom \textit{Toxic Text Detector}. Cieľom práce je poskytnúť používateľom praktický nástroj na identifikáciu potenciálne škodlivého online obsahu pri zachovaní používateľskej kontroly a ochrany súkromia. Riešenie bolo navrhnuté a implementované ako rozšírenie prehliadača Chrome založené na architektúre Manifest V3. Využíva používateľské rozhranie vytvorené v Reacte, content script na prácu s textom webovej stránky, service worker na komunikáciu medzi komponentmi, perzistentné nastavenia a dva režimy inferencie. Lokálny režim vykonáva klasifikáciu priamo v prehliadači, zatiaľ čo vzdialený režim využíva externé API prostredníctvom backendovej služby. Implementované rozšírenie dokáže analyzovať vybraný text alebo textové prvky stránky, označiť potenciálne toxický obsah, vizuálne ho rozmazať a zobraziť detegovanú kategóriu spolu so skóre istoty. Riešenie bolo vyhodnotené prostredníctvom testovania používateľského rozhrania a experimentov s modelmi zameraných na lokálnu a vzdialenú inferenciu. Výsledky ukazujú, že hybridný prístup integrovaný do prehliadača môže poskytnúť praktický kompromis medzi kvalitou detekcie, latenciou, použiteľnosťou a ochranou súkromia. Práca zároveň potvrdzuje, že detekcia toxicity zostáva náročná najmä pri menšinových kategóriách a kontextovo závislých formách škodlivého jazyka.
